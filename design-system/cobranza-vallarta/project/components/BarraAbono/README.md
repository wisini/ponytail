# BarraAbono

How much of the trip a viajero has paid: a 10px `remolino` fill on a `linea` track, rounded, with "$4,000.00 de $8,900.00" and the percentage underneath.

- **Consumer provides:** `pagado` and `total` in pesos. An overpayment is clamped to 100%.
- The bar stays swirl-blue even when an abono is late. Lateness belongs to Estado.
